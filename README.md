# Chelsea Opoku — Portfolio V3

A polished static portfolio site (no build system, no packages, no network dependencies). The primary content is in semantic HTML and works even if JavaScript is blocked.

## Open locally
Unzip the website folder, then open **index.html**. Keep the `assets/` and `source_documents/` folders beside `index.html`.

## Easy offline sharing
Use `Chelsea_Portfolio_V3_Single_File.html` from the separate download for an all-in-one file with embedded imagery. This file is self-contained, except for external links to email and the original Canva site. Source file download buttons are available in the folder version, but the single-file version identifies sources as bundled in the ZIP instead.

## Publish on GitHub Pages
1. Create a public GitHub repo (for example `portfolio`).
2. Upload **the contents of this folder**, so `index.html` sits at the repository root.
3. In Settings → Pages, select `Deploy from a branch`, branch `main`, folder `/(root)`, save.
4. The site will be available at `https://YOUR-USERNAME.github.io/portfolio/`.
